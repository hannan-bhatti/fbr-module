Core Capabilities Built for Pakistan Enterprises

1. 3rd Schedule Retail Tax Engine (SN008)

Bill distributors on discounted Trade Price (Net Rate) while calculating 18% Sales Tax and 4% Extra Tax on the Consumer Retail Price (Fixed/Notified Value). Supports Top-Down MRP, Bottom-Up Tax-Exclusive Retail Value, and manual paisa overrides on products, sale orders, or invoices.

2. Real-Time PRAL Digital Invoicing API

Generates and transmits validated JSON payloads directly to Pakistan FBR across all statutory scenarios (SN001–SN028), logs full API responses in the invoice chatter, and stores the official FBR Invoice Number.

3. WHT 236G Advance Tax Separation

Computes Section 236G advance income tax (0.1% Registered / 0.01% Unregistered) on the untaxed Trade Sales Value, posts it to a dedicated liability account, includes it in Amount Due, and keeps it separate from FBR Sales Tax fields.

4. FBR QR Code & Printable Tax Invoices

Automatically renders the FBR Digital Invoicing logo and verification QR code on posted invoices and QWeb PDF printouts, complete with HS Codes, SRO Schedules, and province details.

Configuration & Invoicing Workflow

1. FBR API & Token Configuration

Configure fbr.api.url and fbr.api.token under Settings → Technical → System Parameters.

2. Customer FBR Registration Type

Assign the customer's NTN/CNIC, Province, and FBR Buyer Type (Registered / Unregistered) on the Contact form.

3. Product HS Code, SRO Schedule & Retail Pricing

Configure HS Code, FBR UOM, SRO Schedule, and optional default Retail Price breakdown on the Product form (or enter prices per order/invoice line).

4. One-Click FBR Submission & QR Verification

Generate the FBR JSON payload, submit directly to FBR, and print the verified QR-coded tax invoice.
